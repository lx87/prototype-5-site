# Практическая работа: Создание веб-анимаций с помощью Lottie и GSAP

## Описание проекта

React-приложение для демонстрации веб-анимаций, созданных с помощью технологий Lottie и GSAP. Проект содержит 5 экранов с различными типами анимаций.

## Особенности

- ✅ **5+ экранов** с различными типами анимаций
- ✅ **Lottie анимации**: иконки, лоадеры, эффекты
- ✅ **GSAP анимации**: интерактивные анимации
- ✅ **Адаптивный дизайн**: работает на всех устройствах
- ✅ **Современный UI**: красивый и интуитивный интерфейс

## Типы анимаций

### Иконки

- Пульсирующее сердце (Lottie)
- Вращающаяся звезда (Lottie)
- Пульсирующий круг (GSAP)
- Прыгающий мяч (GSAP)

### Лоадеры

- Спиннер (Lottie)
- Прогресс бар (Lottie)
- GSAP спиннер
- Интерактивный лоадер

### Другие анимации

- Пульсирующий круг (Lottie)
- Тряска (GSAP)
- Пульсация (GSAP)
- Прыжок (GSAP)
- Затухание (GSAP)

## Установка и запуск

### Требования

- Node.js (версия 14 или выше)
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Запуск проекта в режиме разработки

```bash
npm run dev
```

Приложение откроется в браузере по адресу [http://localhost:3000](http://localhost:3000)

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `build/`

### Просмотр собранного проекта

```bash
npm run preview
```

## Используемые технологии

- **Vite** - быстрый инструмент сборки и разработки
- **React** - библиотека для создания пользовательских интерфейсов
- **React Router** - маршрутизация в React приложении
- **Lottie React** - библиотека для отображения Lottie анимаций
- **GSAP** - мощная библиотека для создания анимаций

## Экраны приложения

1. **Главная** (`/`) - обзор проекта и основные возможности
2. **Иконки** (`/icons`) - коллекция анимированных иконок
3. **Лоадеры** (`/loaders`) - различные типы индикаторов загрузки
4. **Интерактивный** (`/interactive`) - анимации с управлением
5. **Галерея** (`/showcase`) - полная коллекция всех анимаций

## Дополнительная информация

### Lottie анимации

Lottie анимации создаются в формате JSON и могут быть экспортированы из Figma с помощью плагинов:

- **Aninix** - для создания анимаций в Figma
- **LottieFiles** - для экспорта и управления анимациями

### GSAP анимации

GSAP (GreenSock Animation Platform) используется для создания более сложных и интерактивных анимаций, которые требуют программного управления.
