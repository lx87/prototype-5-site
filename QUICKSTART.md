# Быстрый старт

## Установка и запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите проект в режиме разработки:

```bash
npm run dev
```

3. Приложение автоматически откроется в браузере по адресу:

```
http://localhost:3000
```

Примечание: Vite обеспечивает быструю перезагрузку модулей (HMR) для мгновенных обновлений при разработке.

## Структура экранов

- **Главная** (`/`) - обзор проекта
- **Иконки** (`/icons`) - анимированные иконки
- **Лоадеры** (`/loaders`) - индикаторы загрузки
- **Интерактивный** (`/interactive`) - управляемые анимации
- **Галерея** (`/showcase`) - все анимации в одном месте

## Анимации в проекте

### Lottie анимации:

- Пульсирующее сердце (иконка)
- Вращающаяся звезда (иконка)
- Спиннер лоадер
- Прогресс бар лоадер
- Пульсирующий круг

### GSAP анимации:

- Спиннер
- Пульсация
- Прыжок
- Тряска
- Затухание

## Проверка работы

После запуска `npm run dev` вы увидите:

- Главную страницу с демонстрацией анимаций
- Навигацию между 5 экранами
- Работающие Lottie и GSAP анимации
- Адаптивный дизайн
- Быструю перезагрузку при изменении кода (HMR)

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `build/`

## Просмотр собранного проекта

```bash
npm run preview
```

Это запустит локальный сервер для просмотра собранного проекта
